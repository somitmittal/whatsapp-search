📱 Export from WhatsApp

  1. Open a chat → tap ⋮ → More → Export chat
  2. Choose Without media or Include media
  3. Save the .zip → drag it here

☁️ Google Drive

  1. Open drive.google.com
  2. Search WhatsApp Chat
  3. Download .zip/.txt → upload here

⚠ Encrypted backups (crypt14) can't be read. Only exported .txt/.zip work.

  1. Open chrome://extensions → Developer mode
  2. Load unpacked → select extension/
  3. Open web.whatsapp.com
